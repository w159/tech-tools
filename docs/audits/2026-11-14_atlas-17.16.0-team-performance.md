# Atlas 17.16.0: why tasks got slow, and the crew as one team on one tree

Date: 2026-11-14. Model for every arm: claude-sonnet-5-5, effort medium, Claude Code 2.1.325, `claude -p`
with `--allowedTools Bash --permission-mode acceptEdits --setting-sources project,local`. The atlas arms add
`--plugin-dir <snapshot>` and the Atlas Orchestrator output style. The prompt text is the same for every arm
and never names Atlas or the crew. Every run below ended with the full suite green (434 passed), checked by the
harness after the lead exited, and no run touched the tests.

## Fixtures

- fixture-p: 8 Python modules to implement from SPEC.md, 434 tests, plus "Update docs/CHANGELOG.md for the
  change". The project has docs/ (CHANGELOG, ROADMAP) and a README.
- fixture-8b: the same 8 modules and tests, no docs/, no README, and the prompt does not ask for a changelog.

Cold: one `claude -p` from process start to exit. Warm: a lead already started in tmux, timed from the send
to the last result (start and exit excluded). Tokens are input + cache creation + cache read + output, lead
and workers together.

## Cause

1. The router's crew nudge could not be run. It printed `${CLAUDE_PLUGIN_ROOT}` unexpanded and placeholder
   paths, so the lead never started a crew. It wrote all 8 modules itself, one after another, then ran the
   whole suite: one worker, not a team.
2. The Stop gate's paperwork tail. After the code was green the gate still asked for an evidence file, a
   todo board, a verifier dispatch and a findings entry (letters a, b, g, k, m, o). On 17.15.1 that tail
   was about 80 s and about 500k tokens of the 133 s and 841k.
3. Round trips the crew left to the lead: no exit code that meant green, no pass count (so the lead re-ran
   pytest to see one), and the CHANGELOG step (one more read and write turn).

## What changed

- `hooks/gate_rerun.py`: at Stop the gate re-runs the session's own last test command (allowlisted runners
  only, no shell metacharacters, cwd inside the project). Exit 0 writes the evidence and a `verified` finding
  and clears a, b, g, k, m, o; a red re-run blocks with its own output. A green crew `summary.json` for this
  session counts the same way. `ATLAS_GATE_RERUN=off` restores the old gate. Docs letters still apply.
- Router nudge: one runnable command with absolute paths, `--wait 110 --changelog '<one line>'`, and the exit
  code contract (0 green, 1 red, 3 still running).
- `atlas_crew.py`: `run --wait` and `wait` exit 0 only when the summary says ok. Worker DONE messages carry
  their unit check's pass count, and the global check prints one total. `--changelog` has the supervisor add
  the line under `## Unreleased` after a green check, into the changelog the project already keeps; a project
  with no changelog gets none (a new docs/ would arm the docs letters, which cost fixture-8b four extra lead
  turns in run D).
- One tree, no worktrees or branches: the scope matrix sets every team class to `isolation: shared`, and
  workers hand files to each other live with `irc give <path> <peer>` and `irc claim <path>` (a LEASE line on
  the channel; the edit hook, the install step and fix routing all follow the moved lease).

Review between workers stays test based: each worker's Stop hook re-runs its own check, the supervisor
re-runs the global check, and failures go back to the owner of the failing test. No model reviews another
model's diff in the crew path.

## Not met, and costs

- The 1/4 wall time target is not met: 45% warm, 62% cold. The floor is the slowest worker (about 15 s of
  model time for one module plus its tests) plus the lead's two turns.
- The 50% token target is met warm (44%) and missed cold on both fixtures (53%, 64%).
- Dollars: the crew costs more than one prompt on cold runs: $0.257 to $0.266 against $0.184 to $0.199,
  because each of the 8 workers pays its own cache creation. Warm it is $0.262 against $0.213 and $0.354.
- Each lead turn carries about 10k tokens of Atlas system context more than a plain session.
