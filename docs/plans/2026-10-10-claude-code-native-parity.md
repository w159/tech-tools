## 2. Composition decision tree — how a capability composes with native mechanisms

Pick the FIRST match:

1. **Behavior is a guarantee around prompts/tools/lifecycle, no UI, no model traffic** → **classic plugin hooks** (`hooks/hooks.json`; settings/agent/skill frontmatter `hooks`). Events: PreToolUse, PostToolUse, Stop, SubagentStop, UserPromptSubmit, SessionStart/End, WorktreeCreate/Remove, TaskCreated/Completed. Blocking = exit 2 or `decision:block + reason` [Hooks]. *Atlas examples: completion gate (4), channel guard refuse stamp (2-fallback).*
2. **Needs to observe/rewrite model traffic, spawn params, commands, tools, or sessions** → **mod events** (`register(on, options)`; `agent.spawn`, `turn.step`, `tool.call`, `command.run`, `model.complete`, `session.receive/send`, `engine.create`, `telemetry.log`). Observe = `next(e)`; rewrite = `next({...e})`; answer = return without next. `session.receive → {consumed}` keeps a message from Claude; `agent.spawn` model rewrite **replaces the per-invocation model param** (native source 1) [NModCore §1,3] [NTeams R4]. *Atlas examples: routing (8), intents bridge (E), notify diffing (D).*
3. **Needs to draw or replace UI** → **mod `ui.render` sites** (AbovePrompt band, Pane, Spinner, ToolUse, PromptHint…) + elements; Client module for self-ticking art; `$.ui.open/toast/log`. Invalid tree → engine draws its own [Corpus §2-5]. *Atlas examples: band (7), panes (6,7,13).*
4. **Pure packaging, distribution, org enforcement** → **classic plugin manifest + managed settings** (`prependPlugins`, `allowManagedModsOnly`, `disableAllHooks`, deny rules; `sec-default@builtin` guard) [Corpus §8] [NModP].
5. **Neither policy nor UI nor traffic — just data/joining** → plain plugin scripts/skills reading disk (`claude agents --json`, `~/.claude/tasks/`, transcript JSONLs); no hook needed [NSurf A2] [NTeams R6].

### Worked flow (a): worker report → channel → lead inbox

- **Current:** worker finishes → `worker_inbox.py delivery()` stamps `delivered|refused` into the channel dir (note reaches exactly its channel, never injected twice) → lead's SessionStart/user-turn drain() injects wanted notes with MAX_BODY truncation [AMap].
- **Target if native messaging replaces transport:** worker session (or its main-conversation Claude) calls **SendMessage(to: lead session name)** → lead's `crossSessionInbound: accept` delivers between tool calls (running tool never interrupted; idle session gets a new turn); the **LEAD subscribes** via `notify_when_idle` (standalone or attached to a message it sends the worker) to be woken when the worker goes idle — the sender watches the target; a worker attaching `notify_when_idle` on its own message would make the worker watch the LEAD [NInbox]. Hooks still see it (`UserPromptSubmit` fires for cross-session messages) [NInbox] [Hooks]. Channel ledger remains only for: seq numbers, roster/unread counts (SendMessage is plain text, no ack-after-read, no history — messages are never the sender's conversation/files [NInbox]; a `{isDelivered, reason}` receipt exists only on the mods API `$.session.send` [NModCore]). Bedrock/API-key/flag-fetch-off providers: same-machine messaging works v2.1.248+; beyond-machine needs Remote Control — keep worker_inbox.py drain as fallback when messaging is off (`/status` Peer address unavailable).

### Worked flow (b): persona model/effort pinning

- **Today:** `routing.ts resolvePin@27` gates `atlas:` prefix + fork + inherit; `agent.spawn` rewrites omitted/inherit model to the persona pin and records agentId→persona; `turn.step` pins persona effort per request via byAgent map [AModMap].
- **Target on `availableModels`/`CLAUDE_CODE_SUBAGENT_MODEL` era:** pin **model** via subagent-definition frontmatter `model` (per-invocation model param stays free) — resolution order documented [NTeams R4]; org-wide hard pin = `CLAUDE_CODE_SUBAGENT_MODEL` + `_FORCE=1` (v2.1.257+, beats frontmatter); `availableModels` (managed/policy) constrains every path incl. subagent/teammate/skill `model` frontmatter, with substitution + warning [NModP]. Pin **effort**: frontmatter `effort` beats session effort but **loses to `CLAUDE_CODE_EFFORT_LEVEL`**; per-invocation `effort` param (non-fork spawns) v2.1.292+ persists across resume. Residual need: **per-turn effort switching by phase** — only turn.step can do that today → keep the turn.step mod hook (row 8), drop the agent.spawn rewrite (native frontmatter covers it).
