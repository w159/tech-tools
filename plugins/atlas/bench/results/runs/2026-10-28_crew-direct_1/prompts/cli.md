## cli

A pure command line front end with no I/O of its own.

- `USAGE`: the constant string `usage: pkg bump V PART | check V RANGE | validate FILE | resolve FILE | versions NAME`.
- `run(argv, files, reg)` -> `(exit_code, output)`. `argv` is a list of strings (no program name), `files` a dict `filename -> text` standing in for the file system, `reg` a `Registry`. `output` has no trailing newline. Commands:
  - `bump V PART`: `(0, semver.bump(V, PART))`.
  - `check V RANGE`: `(0, "ok")` if `V` satisfies `RANGE`, else `(1, "no")`.
  - `versions NAME`: `(0, versions joined by "\n")`; unknown package: `(1, "error: unknown package NAME")`.
  - `validate FILE`: `(0, "valid")` when the file parses as a manifest; otherwise `(1, "invalid: <ValueError message>")`.
  - `resolve FILE`: parse the manifest, `resolver.resolve(reg, dependencies)`, then `(0, "\n".join(resolver.explain(...)))`. A manifest `ValueError` gives `(1, "error: <message>")`; a `ResolveError` gives `(1, "error: <message>")`.
  - A `FILE` not in `files` (for `validate` and `resolve`): `(2, "error: no such file: FILE")`.
  - Any `ValueError` from `bump` or `check` (bad version, part or range): `(1, "error: <message>")`.
  - Empty `argv`, an unknown command, or the wrong number of arguments for a command: `(2, USAGE)`.
