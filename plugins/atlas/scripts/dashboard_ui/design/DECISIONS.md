# Command Center decisions (foundation task)

Each entry records where MASTER.md/PAGES.md was ambiguous or overridden and what was built instead.

1. **Nav group name "Operate".** MASTER 7.1 calls the group "Agents"; the task brief and user review say Observe / Operate / Improve / Configure. The rail group is "Operate" and contains Fleet, Board, Channel, Colony, Herdr console and the live tree.
2. **Framed fallback keeps a postMessage protocol.** MASTER 4 says none; the task requires it. Accepted inbound: `{type:"atlas:theme", theme, density}` only when `event.source === window.parent`. Posted up: `atlas:attention {count, needInput, level}` and `atlas:title {title}`, targeted at `location.ancestorOrigins[0]` (or the referrer origin, `*` as last resort). Payloads carry no agent data.
3. **Agent age is approximate until a transition is seen.** No server timestamp exists (gap G4). `since` = first time this `state_change_seq` was observed. Records seen only at page load render as `>=3m`-style (`\u2265`) labels; a transition watched in-session renders exact. The inspector says "since this page opened".
4. **No ghost cells.** Todo owners and channel senders without a herdr pane are not drawn as agents (they would flood the strip with `human`, `lead`, names of exited workers). They are exposed as `state.others[]` for the Board and Channel lenses.
5. **"Failed" is derived.** herdr has no failed state; a Done/Ready/unknown agent whose last channel line is `exit N` with N != 0 is shown as Failed (MASTER 5.2 mapping).
6. **Herdr console is its own route.** `#/herdr[?pane=<id>]` (rail item "Herdr console", chord `g x`, palette, inspector "Open in Herdr console") hosts the unmodified `?chrome=full` UI edge to edge under a slim Atlas header (`pages/herdr.js`). `#/agents?lens=console` and `#/console` redirect to it, keeping the query. The Terminal tab keeps `?chrome=pane&theme=<t>`. When Atlas is served through the host gateway (`<meta name="atlas-base">` set) both frames use `location.origin`, never the loopback URL the API reports.
7. **Channel lens is native, no legacy fallback.** `pages/channel-lens.js`: one column. Header (channel name, a select only when there is more than one channel, one dim `main · lead X · branch` line, one row of member chips: click = set To, small icon = open the agent), the message log (last 100, the only scroller) and one composer (To, textarea, Send; Everyone posts to the channel, a member is prompted). No channel tree, Members column, Messages/Board tabs, mode toggle or "Load earlier messages"; the Board lens is the one todo board. The old `pages/irc.js` is deleted. With project "all" and no registry rows the lens shows a project picker, because `GET /api/v2/channels` only creates a main row for a named project.
8. **Colony is native, Board still mounts `pages/work.js`.** `pages/colony-lens.js` lists agent records whose pane is in the colony plus board/channel-only workers (tmux transport workers are never panes). The legacy `/?embed=1` iframe page (`pages/herd.js`) is deleted: it framed one arbitrary pane with no picker.
9. **`g a` is Agents; `g l` is Activity; `g i` is Improve** (was IRC); `g s` stays as an Improve alias; `g d` also opens Agents (old Herd chord); `g x` opens the Herdr console. Documented in the shortcut sheet.
10. **Native `replaceChildren` is banned.** `dom.replace(node, ...children)` filters nullish/boolean (native `replaceChildren(null)` prints the text "null"). Mechanically adopted in health, activity, projects, improve, herd, settings.
11. **Reduced status vocabulary in legacy components.** `Badge`/`StatusDot` now route through `describeStatus` (glyphs.js): old status strings (`ok`, `warn`, `blocked`, `open`, `exited`) map to the MASTER 5.2 states; `ok` reads "Healthy", `warn` "Warning".
12. **Component modules.** `components.js` is a re-export barrel over `ui-core.js`, `ui-overlays.js`, `ui-data.js` and `fleet.js`; `glyphs.js` holds the hex geometry and status table so fleet.js and components do not import each other.
13. **Inspector is one `aside#inspector`.** Docked >=1280 when the canvas stays >=720; otherwise overlay with scrim and focus trap; bottom sheet at <=767. Legacy `openDrawer(Drawer(...))` calls mount into the same region.
14. **Fonts.** Only the six Pretendard chunks listed in MASTER 5.3 plus JetBrains Mono Regular are vendored, `unicode-range` copied from upstream. Korean text falls back to the system CJK face.
15. **Native herdr actions need the gateway origin.** `herdr-actions.js` posts to the host's same-origin `/api/workspace|tab|pane/*` (create, rename, close) and `/api/pane/keys`. Standalone (no `atlas-base`) every action fails with a plain sentence naming the gateway address and the console; send-keys buttons are disabled with the same reason. Role errors from the host (view-only device) are shown as returned. There is no focus route in the host: focusing is opening the agent in the inspector.
16. **Health honesty.** Last OK / Last failure read `Not measured: <reason>` when the backend says `measured:false`, `None recorded in this window` for a measured subsystem with no failure, never the bare word "never". Each card shows a sparkline from `history` (ok+fail per bucket) or the backend's `history_reason`.
17. **Per-page `ensureCss` removed.** `pages-insights.css` is linked once by `index.html`; the pages' own `/ui/css/...` link broke under the `/atlas/` prefix.
18. **Host messages.** `select-pane` (notification click, same origin) opens `#/herdr?pane=`; `herdr:selected-pane` mirrors into the hash while on the console; `herdr:attention` refreshes agents. Mod+Shift+K no longer opens the Atlas palette (it belongs to the console's own).
19. **Polish pass.** (a) Fleet cards show the in-progress task, else the latest channel line, state plus duration ("Working 12m"), a subagent child list, parent link, channel chip and a de-emphasised pane id; they group under `folder@branch` headings. List is a real sortable table (`AgentTable`). Ages use the daemon's `state_changed_at` (source `first_seen` is a lower bound, explained in the title; no more leading glyph). (b) Colony is a supervision tree from `GET /api/v2/channels` (member parent links) plus each lead channel's board (`counts`, `last_note`) joined to panes by name or pane id, the lead board inline, and an honest empty state when no lead has opened a channel. (c) Channel lens shows the full `<main>/<lead>` name with the lead as alias, a parent breadcrumb, member presence and per-member todo counts (server count keys are `pending/in_progress/blocked/completed`). (d) Attention is split: "need input" (amber) and "failed" (red) are agents, "findings" (neutral, red only for fail severity) is doctor output; each pill opens its own list. (e) Health tiles show one "Not measured" plus a "Why not measured" disclosure. (f) The Herdr console header has "Hide herdr sidebar": it clicks the host's own `.sidebar-toggle` (same origin behind the gateway, preference kept in localStorage); the host has no `?sidebar=` param, and a cross-origin frame falls back to a toast naming Mod+Shift+B. Missing backend field: git branch per agent cwd (herd/agents has none), so `folder@branch` headings appear only for projects that have a main channel.
20. **herdr tooling surface (js/integrations.js, js/hp.js, css/integrations.css).** (a) *Projects* gets a "Herdr projects" section above the Atlas project cards: goal, repos, status, threads (id, title, group, branch `hp/<project>/<id>-<title>`, status, PR) with the channel chip `<repo>@<branch>`, Open and Editor buttons, and the needs-you count. Unconfigured shows the backend hint, the exact `herdr-projects configure --dry-run` command with a copy button, and the warning that configure edits agent hook configs. Atlas never runs configure and never starts the ticker. (b) *New thread* is a two-step dialog (form, then a review that states cost and that no profile/yolo/safety flags are sent) posting `/api/v2/projects/hp/threads`; errors show the backend code, why and `detail`, 424 shows the install command. (c) *Settings > Integrations* (first card) and the *Overview* status row read `/api/v2/integrations` and `/api/v2/deck`: installed / enabled / version, docs link, install command + copy when missing, cmux-browser MCP registration, and Captain's Deck is "Unavailable: needs Firstmate" with no pretend board. (d) *Files*: `path[:line|:a-b]` in channel messages, channel/colony board items, the inspector's Recent activity and the new Files tab is a link that POSTs `/api/v2/open-file` with the agent cwd or channel project as `root` and `placement: split`; "Open in editor" (`/api/v2/open-editor`, tode CLI only) sits on the Files tab, the agent menu, hp threads and the palette. 424 opens a modal with the install command, 403/404/400 and 429 are plain toasts; nothing fails silently. tode's code-server is never embedded, linked or proxied. (e) Click-to-focus: `herdr-actions.focusPane(paneId)` (the host has no focus route, see 15) opens the pane in the inspector's Terminal tab, or the Herdr console deep link for a pane Atlas does not list; fleet card Open and colony Open use it. A fleet card whose cwd equals an hp thread cwd shows a `<project> #<id> <branch>` chip. (f) Palette: "Open files for <agent>", "Open in editor: <agent>", "New herdr project thread", "Integrations".
    Backend gaps surfaced honestly: `open-file` needs a file, not a folder, so "Open files" is the Files tab (files mentioned by the agent plus an open-by-path field), not a bare viewer launch. An hp thread cwd is a known root only while an agent runs there or it is an Atlas project, otherwise Editor answers 403 `unknown_root`, shown as such. The host has no pane-focus route.
21. **Colony is one page (supersedes the Herdr console route, colony-lens.js, the Console|Map toggle and the `g x` chord; amends 18).** `#/colony[?pane=<id>]` is only the herdr web UI (`?chrome=full`) filling the canvas, nothing around it. The `herdr` route id is an alias for `colony`; the Herdr console route, `colony-lens.js`, the Console|Map toggle and the `g x` chord no longer exist as features. A pane the frame itself reports (`herdr:selected-pane`) is mirrored into the hash but never rebuilds the iframe; only a pane arriving from outside (deep link, Fleet "Open in Colony", `select-pane`) navigates the frame. The iframe node survives store and SSE ticks.
22. **Supervision lens; Colony stays the herdr frame (amends 1, 6, 8, 19b, 21).** The rail's Operate group is Agents and Colony. `#/colony` is only the herdr frame (`pages/herdr.js`); the native lead -> subagent Colony lens (`colony-lens.js`) was never committed and is not coming back. Lead monitoring lives in Agents as a fourth lens, `supervision` (`pages/supervision-lens.js`): one tree per lead subchannel with every member's todo board, presence, in-progress item and last note; the Channel lens gets a Messages | Board switch with the same rows (`MemberBoard`, `chan-names.js` `memberBoard`). Entry points: the **Supervise** chip on a lead's Fleet card, the **Supervise** button in a lead subchannel header, chord `g u`, palette "Go to Supervision". No new route alias and no nav entry: the lens is reached through Agents so `nav-order.js` (`DEFAULT_NAV`, `MOBILE_TABS`, `NAV_ALIASES`) is unchanged. Where the backend lacks a field the row says so (no pane, no todos, no notes yet) instead of inventing it.
