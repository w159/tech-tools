# tcd12c5ac-SCOPE: Authorization without a scope parameter ends in access_denied (no scope was granted) while the consent page shows 'Access requested: (none)'

- id: tcd12c5ac-SCOPE
- status: verified
- verified_by: LiveSignInVerify
- verified_at: 2026-10-28T12:35:58+00:00

## Evidence
- client without scope: callback error=access_denied; with scope=mcp offline_access: callback code=... issued (same browser, same gateway)
- oidc-provider 9.12.2 lib/actions/authorization/interactions.js:73 'authorization request resolved without requesting interactions but no scope was granted'

## Reproduction
node /tmp/gw/live-client.mjs <base> (no scope) vs node /tmp/gw/live-client-scoped.mjs <base> (scope=mcp offline_access)

## Proposed fix
Send scope=mcp from the client, and/or default the authorization scope to the resource scope in the gateway; surface the provider error_description on the consent page instead of a bare access_denied
