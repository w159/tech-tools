# tcd12c5ac-CSRF: Consent form POST is rejected 403 in every real browser: Referrer-Policy no-referrer makes Chrome send Origin: null, which originOk() refuses

- id: tcd12c5ac-CSRF
- status: verified
- verified_by: LiveSignInVerify
- verified_at: 2026-10-28T12:35:58+00:00

## Evidence
- CDP Network.requestWillBeSentExtraInfo for POST /interaction/<uid>/confirm: origin= null | referer= (empty) | sec-fetch-site= same-origin; server answered 403 'Request blocked - This form was submitted from another site.'
- controlled experiment on 127.0.0.1:9913: a page served with 'referrer-policy: no-referrer' produced origin="null" on a same-origin form POST, while the same page without that header produced origin="http://127.0.0.1:9913"

## Reproduction
open the printed auth URL in Chrome, click Allow on the consent page -> 403 Request blocked

## Proposed fix
Accept Origin: null (or compare the Origin against the request's own host) in originOk(), or drop Referrer-Policy: no-referrer from the interaction pages, or replace the Origin check with a double-submit CSRF token
